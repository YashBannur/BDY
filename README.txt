HOW TO CUSTOMIZE (takes ~2 minutes)

1. Open index.html in any text editor (Notepad, VS Code, TextEdit).
2. Find the block that starts with:  const CONFIG = {
3. Edit:
   - herName      -> her real name
   - fromName     -> your name
   - unlockDate   -> { month: X, day: Y } her birthday. The page stays
                      sealed with a live countdown until 12:00 AM that
                      day, then unlocks itself automatically. Set it to
                      null (no quotes) to skip the seal and let it open
                      anytime.
   - reasons      -> 4 short lines, one per balloon
   - photos       -> filenames + a one-line caption each
   - letter       -> your birthday letter, as one paragraph

4. Put her photos inside the "photos" folder, named exactly like
   you listed them in CONFIG (photo1.jpg, photo2.jpg, etc).
   JPG or PNG both work. Keep each photo under ~3MB so it loads fast.

5. Save the file, then double-click index.html to open it in your
   browser (Chrome/Safari/Edge — any modern browser works).

TO SHOW HER ON YOUR PHONE
   Copy the whole "birthday-surprise" folder (index.html + photos
   folder together, don't separate them) to your phone via
   AirDrop, USB, or a WhatsApp "file" attachment (not "photo" —
   that compresses it), then open index.html in your phone's browser.

NOTES
   - No internet needed except to load the two Google Fonts on first
     open. If you want it fully offline, that's an easy tweak — just ask.
   - There's a "Replay" button on the last screen if she wants to
     go through it again.
